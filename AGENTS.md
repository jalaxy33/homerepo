# homerepo

Not a project. A public repo for things that belong to no single project: scripts
and config snippets shared across a few of them, references, notes not yet claimed.

Consequences: no uniform layout, directories unrelated to each other, no build
system, nothing runs. Don't look for consistency. Don't add READMEs or scaffolding
to "tidy up".

Real work belongs in the project's own repo.

- Something stays here only if a project needs it and the project has no place for it.
- Chat logs and drafts travel with the session; they don't land here.
- Run `git diff --cached` before committing: a public repo's history can't be deleted.
